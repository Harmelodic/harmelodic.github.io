# macOS Device Support Tracker

[Android Update Tracker](https://www.androidupdatetracker.com/) is very useful.

As are the tables on Wikipedia that provides information about macOS support for
different [intel-based MacBook Pros](https://en.wikipedia.org/wiki/MacBook_Pro_(Intel-based)#Software_and_operating_systems)
and other tables ofr macOS support for the other classes of Apple devices.

But nowhere (that I found) brought all macOS-capable devices onto one table to show general macOS support over the
years. Here's my attempt at making that!

It goes all the way back to the original Macintosh 128K, and I'll try to keep it up to date with support as new devices
are released.
