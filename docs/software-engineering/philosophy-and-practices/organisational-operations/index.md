# Organisational Operations Overview

Different organisations work differently, but they ultimately all have _functions_ that need to be fulfilled by some
arrangement of _organisational operations_.

This section of the site covers various topics related to the "organisational operations"-side of software engineering
as well as various articles on other organisational operations topics
(e.g. [administrative functions](administrative-functions.md) or management advice).
