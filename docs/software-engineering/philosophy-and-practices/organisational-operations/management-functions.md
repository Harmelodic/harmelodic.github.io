# Management Functions

- We tend to think of management / governance / administration in different "roles"
- Those roles have multiple functions
- If we break up the roles into just the pure functions, we can reorganise things differently, and invent different
  roles.
- Some roles contain functions that we actually don't want / value
- As we break up roles and deduce functions, we can classify functions on a Value spectrum (Needed, Wanted, Undesirable,
  etc.)
- As organisations ways of working and cultures shift, different functions get moved around (e.g. architecture is
  getting decentralised more nowadays) - which leaves question as to what roles actually do, and whether they are
  beneficial.
- Knowing functions of roles, and being able to reorganise when things change, keeps us well-functioning and may help
  us avoid bullshit jobs.
