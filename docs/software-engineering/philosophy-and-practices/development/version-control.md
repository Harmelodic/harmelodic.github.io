# Version Control

Problem: Need to store your code for your software somewhere centrally so you can:

- Work on it collaboratively with others
- Share the code (if open source or inner source)
- Ship the software

Solution: Use version control.

Git the main version control used by the industry (at time of writing (2025)).

Sourcing stuff from code in version control has become more and more common with things like _GitOps_ and
_Infrastructure as Code_.

Generally, if you can store something as code, you should. This gives you a starting point for all further automations.

## Version Control tools

- [Bitbucket - Atlassian](https://www.atlassian.com/software/bitbucket)
- [Git](https://git-scm.com/)
- [GitHub](https://github.com/)
- [GitLab](https://gitlab.com/)
- [Mercurial](https://www.mercurial-scm.org/)
- [SVN - Apache Subversion](https://subversion.apache.org/)
